# Career Snowflakes

Career Snowflakes — небольшой pet-проект на Go и React для наглядного отслеживания профессионального развития по нескольким карьерным трекам. Концепция вдохновлена карьерной матрицей, предложенной инженерами Medium.

Главный экран — интерактивный snowflake-график: окружность разделена на направления развития, а каждое направление — на последовательные сегменты. Сегменты показывают текущий прогресс и позволяют открыть подробное описание соответствующего этапа.

## Архитектура и стек

- Приложение собирается на Wails 3.
- React и TypeScript отвечают за интерфейс, график и взаимодействие с матрицей.
- Go отвечает за работу с файлами, схемами данных, импортом и экспортом; эту логику не следует дублировать во фронтенде.
- Интерфейс использует Tailwind CSS и shadcn/ui на базе Base UI.
- Визуальная тема — Gruvbox.
- Для форматирования и линтинга фронтенда используется экосистема Oxc.
- Версия среды выполнения — Node.js 24 LTS.
- Менеджер пакетов фронтенда — pnpm; не создавайте lock-файлы других менеджеров.

Проект развивается небольшими последовательными шагами. Не добавляйте преждевременные абстракции, зависимости или функциональность за пределами текущей задачи.

## Переписывание фронтенда

- `frontend/src` — единственная актуальная реализация фронтенда. Она пишется заново и всегда должна оставаться компилируемой.
- `frontend/src/app` — сохранённая основа приложения: точка композиции, маршруты и глобальная тема. Развивайте её постепенно вместе с новым кодом.
- `frontend/_legacy` — замороженный справочник по прежней реализации. Не импортируйте его из `src`, не включайте в сборку и не исправляйте там код попутно.
- Перед поиском старого компонента или вёрстки прочитайте карту в `frontend/_legacy/AGENTS.md`, затем используйте точечный `rg` по имени компонента, тексту интерфейса или CSS-классу. Не читайте весь legacy-код целиком.
